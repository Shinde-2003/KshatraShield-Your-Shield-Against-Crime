# KshatraShield – Your Shield Against Crime
An AI-powered crime reporting and analysis platform built with Python, Flask, MongoDB, NLP, JWT authentication, multilingual support, geolocation services, and real-time media evidence capture.

## Overview

KshatraShield is an AI-powered web-based crime reporting and analysis platform designed to modernize the process of crime reporting and improve communication between citizens and law enforcement agencies.

The platform enables users to report crimes using text, voice, images, videos, and audio evidence while ensuring privacy, security, and accessibility through multilingual support and anonymous reporting.
